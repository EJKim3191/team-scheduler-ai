# v0.1.6 — 랜딩 페이지 & 인터랙티브 온보딩

**릴리스 일자:** 2026-06-12  
**태그:** `v0.1.6`

## 개요

첫 방문 사용자를 위한 **스테이지형 랜딩 페이지**(`/landing`)를 추가했습니다.  
오프닝 → 테트리스 체험 → AI 데모 → 서비스 소개까지 한 화면(`100dvh`, 스크롤 없음)에서 순차적으로 진행됩니다.

---

## 주요 기능

### 1. 오프닝 (`Opening`)

- **BrandMark** 서비스명(모여라 · Moyora) 표시
- 맨트 + 아무 키 입력으로 다음 스테이지 진행
- 첫 방문 시 `has-visited` 쿠키 저장 (영구 만료)

### 2. 테트리스 체험 (`TetrisStage` × 2)

- Canvas 기반 테트리스 엔진 (`engine.js`, `constants.js`)
- 스테이지별 intro 오버레이 (설명 확인 후 시작)
- **미션 1:** 라인 1개 클리어 시 다음 단계
- **미션 2:** 카오스 규칙 적용 (듀얼 블록, 랜덤 주입, 배속 등)
- `chaosSchedule` API로 규칙 타이밍 조절 가능
- `isActive` / `isPlaying` / `instanceId`로 스테이지 전환 시 게임 초기화

### 3. AI 테트리스 시나리오 (`TetrisScenario`)

- "그럼 약간의 도움을 받아볼까요?" 인트로 → 채팅 + AI 자동 플레이
- `TetrisAuto` + `autoPlayer.js` 휴리스틱 AI
- 7초 경과 시 강제 다음 스테이지 이동

### 4. 파이널 (`Finale`)

- 중앙 헤드라인 + CTA (`/login`)
- 서비스 mockup 5종 구름 카드 순차 등장
  - 팀 주간 일정 (상단)
  - 채팅 (우상단)
  - 팀원 관리 (좌하단)
  - 일정 수정 + 마우스 포인터 (좌상단)
  - 팀 선택·생성 (우하단)

### 5. 공통 UI

- 우측 상단 **로그인 / 회원가입** 텍스트 링크 (`page.jsx`, absolute)
- 공통 **BrandMark** 컴포넌트 (`app/landing/BrandMark/`)
- `LandingContent` 스테이지 스택 + CSS 페이드 전환
